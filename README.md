# Little Knight

A 2D roguelike action game built with Unity 6 (C#). Control a little knight, fight through levels, and build your own playstyle with 9 unique buffs.

## ✨ Features

- **Roguelike Action** — Fight through levels with melee combat
- **Build Your Own Playstyle** — Combine 9 unique buffs to create your own build
- **9 Unique Buffs** — +ATK, +SPD, +ASPD, +HP, Thorns, Lifesteal, and more
- **State Machine** — Clean AI and player state management
- **Object Pooling** — Efficient memory management for projectiles and enemies
- **JSON Serialization** — Save/load game data
- 
## 🛠️ Tech Stack

- **Engine**: Unity 6
- **Language**: C#
- **Patterns**: State Machine, Object Pooling, Singleton
- **Data**: JSON Serialization
- **Platforms**: WebGL, Android
